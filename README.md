## アプリ名
Tkinter Kakeibo App

## 概要
PythonのGUIライブラリーであるTkinterを好かって作成した家計簿アプリです。　　
支出の登録・一覧表示・合計金額の確認など、日々の家計管理を簡単に行えるように設計しています。　　
学習目的で作成しており、○○の理解を深めることを目的としています。

## 主な機能
・支出の記録  
・カレンダー形式での日付管理  
・前月・次月への切り替え  
・月ごとのカレンダー表示  
・GUIによる操作  

## 使用技術
・Python 3.14  
・Tkinter
